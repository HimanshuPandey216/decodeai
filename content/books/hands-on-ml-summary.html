Book Breakdown: Hands-On Machine Learning (Aurélien Géron)

Original work by Aurélien Géron. Community study notes & concept breakdown by Decode AI.

Part 1: Classic Machine Learning with Scikit-Learn

Key takeaways on End-to-End ML project workflow:

  • Data Pipeline: Using ColumnTransformer, Pipeline, and SimpleImputer to prevent data leakage between train/test splits.
  • Classification: Precision/Recall tradeoff, ROC curves, Confusion Matrices, and multiclass strategies (One-vs-Rest / One-vs-One).
  • Ensembles: Bagging, Random Forests, AdaBoost, and Gradient Boosting (XGBoost / LightGBM).

Part 2: Neural Networks and Deep Learning

Building custom architectures with Keras and TensorFlow 2:

  • Vanishing Gradients: Solutions using He/Xavier initialization, SELU/ReLU activations, and Batch Normalization.
  • Transfer Learning: Fine-tuning pre-trained image classifiers (ResNet, EfficientNet).
