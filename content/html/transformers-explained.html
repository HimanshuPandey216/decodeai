Transformers Architecture Explained: From QKV to Multi-Head Attention

Key Takeaway: The Transformer architecture, introduced by Vaswani et al. in 2017, replaced recurrent neural networks (RNNs) by allowing parallel processing of sequence data through the Self-Attention Mechanism.

1. Why Transformers Replaced RNNs

Traditional Recurrent Neural Networks processed text sequentially (token by token). This created two major bottlenecks:

  • Vanishing Gradients: Difficulty capturing long-range dependencies across distant words in a sentence.
  • Lack of Parallelization: Token $t$ required hidden state $h_{t-1}$, making GPU hardware acceleration inefficient.

2. Scaled Dot-Product Attention

At the core of every Transformer block is the calculation of Query ($Q$), Key ($K$), and Value ($V$) projections:

Attention(Q, K, V) = softmax( (Q Kᵀ) / √dₖ ) V

Where:

  • Q (Query): What the current token is searching for.
  • K (Key): What each token in the sequence offers.
  • V (Value): The actual representation vector of each token.
  • dₖ: The dimension of the Key vectors (used to scale dot products and stabilize gradients).

3. PyTorch Implementation of Self-Attention

import torch
import torch.nn as nn
import math

class SelfAttention(nn.Module):
    def __init__(self, d_model):
        super().__init__()
        self.d_model = d_model
        self.q_linear = nn.Linear(d_model, d_model)
        self.k_linear = nn.Linear(d_model, d_model)
        self.v_linear = nn.Linear(d_model, d_model)

    def forward(self, x):
        Q = self.q_linear(x)
        K = self.k_linear(x)
        V = self.v_linear(x)

        # Dot-product Q & K
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_model)
        attention_weights = torch.softmax(scores, dim=-1)
        
        # Multiply by V
        output = torch.matmul(attention_weights, V)
        return output, attention_weights

4. Positional Encoding

Since self-attention operates on sets of vectors symmetrically, order information is lost without Positional Encoding. Transformers add sine and cosine functions of varying frequencies directly to input embeddings.
