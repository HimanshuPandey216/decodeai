01Part I · Foundations

What is a Transformer?

A Transformer is a neural network architecture, introduced in 2017, that reads a whole sequence at once and figures out, mathematically, which parts of that sequence matter to each other.

Unlike Recurrent Neural Networks (RNNs) which process tokens sequentially, Transformers rely on self-attention to process all tokens in parallel while modeling long-range dependencies efficiently.

02Part II · Tokenization & Embeddings

Tokenization & Embeddings

Raw text is converted into subword tokens and mapped into dense vector spaces (embeddings) so neural networks can process semantic relationships numerically.

03Part III · Attention Mechanism

Self-Attention & QKV Matrices

Query (Q), Key (K), and Value (V) projections allow the model to calculate relative importance between every pair of words in a sequence using softmax(QKᵀ / √d_k)V.
