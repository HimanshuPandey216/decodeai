Quick Revision

High-value differences

ConceptsRemember
Mean vs MedianMean uses every value and is sensitive to outliers; median is robust.
Correlation vs CausationCorrelation measures association; it does not prove cause.
Classification vs RegressionClass predicts categories; regression predicts numeric values.
Bagging vs BoostingBagging reduces variance through parallel models; boosting builds sequentially to reduce error.
RF vs XGBoostRF is bagged trees; XGBoost is optimized gradient boosting.
L1 vs L2L1 can drive coefficients to zero; L2 shrinks them smoothly.
Precision vs RecallPrecision: correctness of positive predictions. Recall: positives successfully found.
Normalization vs StandardizationNormalization commonly maps a range; standardization centers/scales by mean and SD.
Underfit vs OverfitUnderfit misses structure; overfit memorizes noise.
Batch vs EpochBatch = one chunk of training examples; epoch = one full pass.
RAG vs Fine-tuningRAG supplies external context at inference; fine-tuning changes model parameters.

Statistical test chooser

SituationTypical test
One mean vs known valueOne-sample t/z test depending on assumptions and known variance
Two independent meansIndependent t-test
Paired measurementsPaired t-test
Categorical associationChi-square
3+ group meansANOVA
Experiment/controlA/B test + appropriate metric/test

Formula Sheet

Mean

x̄ = (1/n) Σxᵢ

xᵢ = observation, n = number of observations.

Variance

s² = Σ(xᵢ−x̄)²/(n−1)

s² = sample variance; n−1 is Bessel's correction.

Standard deviation

s = √s²

Square root of variance; same units as the data.

Probability

P(A)=favorable outcomes / total outcomes

Bayes

P(A|B)=P(B|A)P(A)/P(B)

Updates belief about A after observing B.

Covariance

Cov(X,Y)=Σ(xᵢ−x̄)(yᵢ−ȳ)/(n−1)

Correlation

r=Cov(X,Y)/(sₓsᵧ)

Standardized linear association, from −1 to +1.

Linear regression

ŷ=β₀+β₁x

β₀ = intercept; β₁ = slope; ŷ = prediction.

Logistic regression

p=1/(1+e⁻ᶻ), z=β₀+βᵀx

Maps a linear score to a probability.

MAE

MAE=(1/n)Σ|yᵢ−ŷᵢ|

MSE

MSE=(1/n)Σ(yᵢ−ŷᵢ)²

RMSE

RMSE=√MSE

R²

R²=1−SSres/SStot

SSres = residual sum of squares; SStot = total sum of squares.

Precision

TP/(TP+FP)

Recall

TP/(TP+FN)

F1

2PR/(P+R)

Entropy

H=−Σpᵢ log₂pᵢ

Gini impurity

G=1−Σpᵢ²

Gradient descent

θ←θ−η∇J(θ)

θ = parameters; η = learning rate; J = objective.
