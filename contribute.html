Contribution Workflow

1

Create Your Content File

Write your study note or summary and place the HTML/PDF file into /content/notes/, /content/html/, or /content/pdfs/.

2

Update data/resources.json

Add a single JSON object containing your title, tags, level, type, author, and file path.

3

Submit Pull Request on GitHub

Submit your pull request. Once merged, Decode AI automatically displays your resource live!
